# yscoopy

ycookiey's Scoop bucket for Windows applications

## Installation

Add this bucket to Scoop:

```powershell
scoop bucket add yscoopy https://github.com/ycookiey/yscoopy
```

## Available Apps

### yClocky

Minimal and stealthy desktop clock for Windows

```powershell
scoop install yscoopy/yclocky
```

Features:
- Minimal design with no window frame
- Stealth mode (hidden from taskbar and Alt+Tab)
- Ghost mode (auto-fade when cursor approaches)
- Capture protection (excluded from screenshots and screen sharing)
- Customizable fonts, colors, and opacity
- Startup support

**Homepage**: https://github.com/ycookiey/yClocky

### yCursory

IME cursor indicator with glow effect for Windows 11

```powershell
scoop install yscoopy/ycursory
```

Features:
- Mouse cursor glow (Blue: English mode, Red: Japanese mode)
- Caret indicator for text input positions
- 60fps high-speed tracking with zero latency
- System tray integration
- Lightweight (EXE: ~120KB, Memory: ~1.4MB)
- Two glow styles: Heavy (emphasized) and Light (balanced)

**Homepage**: https://github.com/ycookiey/yCursory
