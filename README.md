# yscoopy

A [Scoop](https://scoop.sh/) bucket for ycookiey's Windows apps.

## Usage

```powershell
scoop bucket add yscoopy https://github.com/ycookiey/yscoopy
scoop install yscoopy/<app>
```

## Apps

| App | Description |
| --- | --- |
| [dirtygit](https://github.com/ycookiey/dirtygit) | Terminal dashboard that finds git repositories under chosen folders and shows which have uncommitted or unpushed changes |
| [yclocky](https://github.com/ycookiey/yClocky) | Minimal frameless desktop clock for Windows that stays out of the taskbar, Alt+Tab and your clicks |
| [ycursory](https://github.com/ycookiey/yCursory) | IME cursor indicator with glow effect for Windows 11 |
| [yhooky](https://github.com/ycookiey/yhooky) | One fast binary that runs Claude Code hooks: rules in TOML files plus built-in checks |
| [yhwndy](https://github.com/ycookiey/yhwndy) | Windows tray tool that makes windows semi-transparent or borderless with hotkeys, and fades them out as the mouse comes near (Ghost Mode) |
| [ymonitory](https://github.com/ycookiey/yMonitory) | Always-on-top overlay that shows CPU and memory usage with graphs |
| [ystrokey](https://github.com/ycookiey/yStrokey) | Keystroke visualizer (OSD) for Windows |
| [ytaskbary](https://github.com/ycookiey/ytaskbary) | Keeps the Windows 11 taskbar hidden and shows it only while the Start menu is open |
| [ytasky](https://github.com/ycookiey/ytasky) | A time-blocking scheduler for the terminal, with a TUI, a CLI and an MCP server |
| [ywatchy](https://github.com/ycookiey/ywatchy) | Watches project folders to link Claude Code skills into ~/.claude/skills and keep CLAUDE.md files in sync with a store folder |
